# Hangman_Game
# Overview
This project is a simple-textbased hangman game developed in python.The player attempts to guess a randomly selected word by entering one letter at a time.The game displays the correctly guessed letters and tracks the number of remaining attempts.

# Features
1.Random word selction
2.Win and lose conditions
3.Maximum of six incorrect attempts

# Technologies
1.Python
2.Random module
3.loops and conditional statements
4.String and lists
